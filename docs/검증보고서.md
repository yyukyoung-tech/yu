## 결과 범위

Windows x64 호스트, Node.js v24.22.1, 한글과 공백을 포함한 프로젝트 경로에서 실행했습니다. 교사/학생은 모두 가상 자료입니다. 외부 배포나 실제 학생 데이터 사용은 하지 않았습니다.

1.0.1 최종 서버 자동 테스트 **19개**, 화면 자동 테스트 **1개**, TypeScript 검사 및 Vite 프로덕션 빌드를 실행했습니다. 최초 미구현 실패를 확인하고 구현했으며, 정책 변경 경쟁과 백업 누락은 별도 실패 재현 후 수정했습니다. 공개 폴더 데이터 저장 차단과 Pages 개인정보 입력 방지 테스트를 추가했습니다. 알려진 의존성 취약점은 수정 후 전체 audit 0건입니다. 자세한 수정 내역은 공개전보안검토.md, 실행 결과는 ZIP의 test-results/server-1.0.1.txt에서 확인하세요.

## 미검증·운영 제한

- 학교 내부 서버 게시, 실제 학교 HTTPS 인증서·프록시·방화벽·다른 교실 PC 접속은 환경과 승인이 없어 실행하지 않았습니다.
- Windows 로컬 Node 서버에서 실행했으며 Windows EXE/MSI 설치·제거 검증은 해당하지 않습니다. 웹사이트 방식이므로 설치 파일은 생성하지 않았습니다.
- 크롬·엣지의 독립 설치본, 실제 한글 Windows 사용자 계정, 완전한 인터넷 차단 상태, 업로드 중 실제 네트워크 차단/전원 종료는 별도 시험하지 않았습니다. 한글/공백 폴더와 네트워크 실패 UI는 확인했습니다.
- 동시 32개 테스트는 작은 합성 파일입니다. 300명 동시 접속·50MB 동시 전송·수업 시간 장기 부하·서버 디스크 고갈 전체 상황은 미검증입니다.
- 실제 엔트리·한글·오피스의 모든 버전/변형, 모든 문서 내부 구조, 악성코드 탐지/백신 연동은 미검증입니다. 파일 검사는 악성코드 안전 보증이 아닙니다.
- 1.0.0 재시작과 백업 복원은 확인했으나 미래 버전으로의 실제 업그레이드는 미검증입니다. 복원은 운영자 CLI를 사용하며 브라우저에서 서버 데이터를 즉시 덮어쓰지 않습니다.
- 파일 업로드 완료 직후 통신이 끊기면 서버 저장과 확인번호 수신이 엇갈릴 수 있습니다. 중복 안내가 나오면 교사가 현황을 확인해야 합니다. 잃어버린 확인번호 복구·학생 본인 인증·악성 제출 식별은 지원하지 않습니다.
- 보유기간 정리는 수동 실행입니다. 학생 명단과 백업·내보낸 파일은 별도 정리합니다. 삭제 후 파일 정리가 실패하면 남은 파일 수를 표시합니다.
- 정전/프로세스 강제 종료는 DB에서 참조하지 않는 임시·고아 파일을 남길 수 있습니다. 여러 서버 프로세스를 같은 데이터 폴더에 동시에 실행하지 마세요.
- 백업은 암호화되지 않은 개인정보 자료입니다. 학교 승인 암호화 저장장치와 접근 권한이 필요합니다. 의존성 취약점 전수 진단·침투 테스트·법률 검토를 완료했다는 뜻은 아닙니다.
